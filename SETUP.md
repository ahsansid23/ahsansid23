# GitHub profile README setup

To activate this profile README, create a **public** GitHub repository named `ahsansid23` and copy this README.md to its root. GitHub displays the root README on your profile when the repository name matches your username.

The links in the profile README expect a public repository named `cloud-network-engineering-portfolio` with the included `projects/` directory structure. If you choose a different portfolio repository name, update those project links before publishing.
